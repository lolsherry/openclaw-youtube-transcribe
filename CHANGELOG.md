# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-03-19

Initial public release.

### Added

- OpenClaw workspace skill: `skills/youtube-transcribe`
- End-to-end shell script for YouTube audio download + local Whisper transcription
- Multi-format transcript output: `txt`, `srt`, `vtt`, `tsv`, `json`
- English README
- Simplified Chinese README
- SVG banner for repository landing page
- Example output pages in English and Chinese
- MIT license
- Social preview assets

### Notes

- Default output directory is `${HOME}/Documents/youtube-transcripts`
- Default language is `zh`
- Default model is `small`
- Default output format is `all`
